Context

The project has a working FSBL + Application with LTDC display. The goal is to add live camera capture (IMX335 via DCMIPP/CSI) and display it full-screen on the 800×480 LCD, structured for seamless ML integration later. CMW (Camera Middleware) from the ST modelzoo is used instead of raw HAL — this is the key architectural decision: when ML is added, PIPE2 is simply enabled with no redesign.

Confirmed sensor: IMX335 (B-CAMS-IMX), confirmed by reference project 3 (DCMIPP_ContinuousMode) which targets this exact board and camera module.

Phase 1: CubeMX Changes

Open Template_FSBL_XIP.ioc → select Appli context for all changes below.

1.1  Enable I2C1

  • Connectivity → I2C1 → Mode: I2C
  • CubeMX assigns PH9 (SCL, AF4) and PC1 (SDA, AF4) — matches BSP stm32n6570_discovery_bus.h
  • After code regeneration: delete any HAL_I2C_MspInit/MspDeInit stubs CubeMX generates — the BSP bus driver (stm32n6570_discovery_bus.c) owns I2C1 MSP init

1.2  Enable DCMIPP

  • Connectivity → DCMIPP → Mode: CSI2 interface
  • After code regeneration: delete the generated MX_DCMIPP_Init() function body and any HAL_DCMIPP_MspInit/MspDeInit stubs — CMW owns DCMIPP MSP init

1.3  Enable RAMCFG

  • System Core → RAMCFG → Enabled
  • Adds HAL_RAMCFG_MODULE_ENABLED to stm32n6xx_hal_conf.h. No generated code needed.

1.4  Clock Configuration

ClockSourceDividerResult
IC16 (LTDC)PLL1÷4825 MHz
IC17 (DCMIPP)PLL1÷4300 MHz
IC18 (CSI byte)PLL1÷6020 MHz
  • Set LTDC clock source → IC16
  • Set DCMIPP clock source → IC17
  • Set CSI clock source → IC18

1.5  Reconfigure LTDC Layer 0 (camera feed layer)

  • Multimedia → LTDC → Layer 0:
    • Window: X0=0, Y0=0, X1=800, Y1=480
    • Pixel Format: LTDC_PIXEL_FORMAT_RGB565
    • ImageWidth=800, ImageHeight=480
    • FBStartAdress=0 (set at runtime)
  • Layer 1: disable (not needed for camera-only stage)

1.6  Add Camera GPIO Pins

  • PC8: Output PP, no pull, Very High speed, initial Low → label: CAM_NRST
  • PD2: Output PP, no pull, Very High speed, initial Low → label: CAM_EN
  • Assign both to Appli context

1.7  NVIC

  • DCMIPP global interrupt: Enabled, preempt priority = 7
  • CSI global interrupt: Enabled, preempt priority = 7

1.8  Regenerate → Post-Cleanup

After generating code, manually delete these CubeMX-generated stubs to avoid conflicts with CMW:
  • MX_DCMIPP_Init() in main.c — delete entire body (CMW replaces it)
  • HAL_DCMIPP_MspInit / HAL_DCMIPP_MspDeInit in stm32n6xx_hal_msp.c
  • HAL_I2C_MspInit / HAL_I2C_MspDeInit in stm32n6xx_hal_msp.c (if generated)

app_camera.c — implementation outline:

  • Frame buffer declared __attribute__((section(".axisram3_bss"), aligned(32))) at 0x34200000
  • App_Camera_Init():
    1. Enable AXISRAM3 clock + RAMCFG (HAL_RAMCFG_EnableAXISRAM)
    2. Configure RIF for DCMIPP and CSI master/slave attributes
    3. CMW_CAMERA_Init() with width=0, height=0, fps=30

  • App_Camera_Start(): CMW_CAMERA_Start(DCMIPP_PIPE1, camera_fb, CMW_MODE_CONTINUOUS)
  • App_Camera_IspUpdate(): CMW_CAMERA_Run()
  • CMW_CAMERA_PIPE_FrameEventCallback(): increment camera_frame_received on PIPE1

Appli/Src/stm32n6xx_hal_msp.c

Add inside /* USER CODE BEGIN 1 */ — override of CMW's __weak function:

HAL_StatusTypeDef MX_DCMIPP_ClockConfig(DCMIPP_HandleTypeDef *hdcmipp)
{
    RCC_PeriphCLKInitTypeDef cfg = {0};
    // DCMIPP: IC17 = PLL1/4 = 300 MHz
    cfg.PeriphClockSelection = RCC_PERIPHCLK_DCMIPP;
    cfg.DcmippClockSelection = RCC_DCMIPPCLKSOURCE_IC17;
    cfg.ICSelection[RCC_IC17].ClockSelection = RCC_ICCLKSOURCE_PLL1;
    cfg.ICSelection[RCC_IC17].ClockDivider = 4;
    HAL_RCCEx_PeriphCLKConfig(&cfg);
    // CSI: IC18 = PLL1/60 = 20 MHz
    cfg.PeriphClockSelection = RCC_PERIPHCLK_CSI;
    cfg.ICSelection[RCC_IC18].ClockSelection = RCC_ICCLKSOURCE_PLL1;
    cfg.ICSelection[RCC_IC18].ClockDivider = 60;
    return HAL_RCCEx_PeriphCLKConfig(&cfg);
}

Phase 7: Initialization Order (Critical)

The order below is mandatory. Deviating from it will cause hard faults or silent failures. 
1.  MPU_Config()               ← includes AXISRAM3 non-cacheable region
2.  SCB_EnableICache/DCache()
3.  HAL_Init()
4.  MX_GPIO_Init()             ← CAM_NRST + CAM_EN configured here (from CubeMX)
5.  MX_LTDC_Init()             ← now uses IC16/PLL1/÷48 = 25 MHz
6.  SystemIsolation_Config()   ← LTDC + DCMIPP + CSI RIF
7.  LCD_ON / BL_CTRL GPIO set
8.  App_Camera_Init()          ← RAMCFG → CMW_CAMERA_Init → pipe config
9.  HAL_LTDC_SetAddress()      ← point Layer 1 at camera_fb (0x34200000)
10. App_Camera_Start()         ← HAL_DCMIPP_CSI_PIPE_Start + sensor streaming
11. while(1): App_Camera_IspUpdate()
Critical: AXISRAM3 RAMCFG must be enabled (step 8) before any access to 0x34200000. DCMIPP RIF must be configured (step 6 or inside step 8) before CMW_CAMERA_Init.

Phase 8: Verification Steps

  1. Build: Zero errors. Check .map file: camera_fb at 0x34200000, size 768 KB.
  2. Debug — Sensor probe: Step into CMW_CAMERA_Init → confirm IMX335 chip ID 0x0235 returned from I2C read.
  3. Debug — Frame callback: Breakpoint in CMW_CAMERA_PIPE_FrameEventCallback — should hit every ~33 ms at 30 fps.
  4. Visual: LCD shows live camera feed at 800×480, updating smoothly.
  5. ISP: After 2–3 seconds, brightness/white balance stabilizes (AEC/AWB converging).
